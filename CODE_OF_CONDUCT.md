# Code of Conduct

OpenBattlefield follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, critique work not people, and keep technical arguments
grounded in evidence. Harassment, discrimination and personal attacks are not tolerated.

Reports: open a private security advisory on GitHub or contact the maintainers listed in the
repository settings. Reports are handled confidentially.
